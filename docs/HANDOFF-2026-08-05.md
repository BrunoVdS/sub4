## 3. The rules that keep costing when forgotten

Every one of these cost a patch today.

- **A migration is history.** Once run against a persistent database its body is
  never edited. Vocabularies inside a migration are FROZEN literals, coupled to
  the Swift enums by test.
- **Anything that is data rather than state should say `nonisolated` when it is
  written**, not after a build says so. `SWIFT_DEFAULT_ACTOR_ISOLATION =
  MainActor` isolates everything that does not say otherwise. Hit three times
  today: `DataCorrections` (258), `JSONEncoder.sub4` (264a), and a default
  argument evaluated at the call site.
- **A synthesised `init(from:)` does not use Swift default values.** Any new
  property on a persisted `Codable` must be Optional, or every file already on
  disk fails to decode *entirely*. `Cache.bikes` and `Cache.retired` are
  optional for this reason and will stay so.
- **`Self` in a default argument** is covariant `Self` even on a `final class`
  and the compiler refuses it. Name the type.
- **`#expect(x.allSatisfy(\.keyPath))`** demands a `try` — the macro decomposes
  into a `rethrows` call. The closure form usually compiles; the key-path form
  does not. Hoist into a local.
- **Sweep from the MECHANISM.** When a signature or a type changes, enumerate
  every *use* of every value whose type changed, in **both** `Sub4/` and
  `Sub4CoreTests/`. Missing the test target cost 265a; stopping at the binding
  site rather than reading to the end of the function cost 267a.
- **Never assert `Sub4Migrations.all.last == …`.** The invariant is
  `all == all.sorted()`.

## 6. The finding that matters most, and it is not a defect

**The monthly review cannot be sent at all.** `Review.payload()` builds nine
sections; five are Strava-derived and blocked by ADR-0002 §5.3/§5.10 —
coverage, flags, adherence, running volume, pace. `ReviewPayload.isUsable` is
`blocked.isEmpty`, `ReviewRequest.prompt` returns nil, and `ProposalStore.run`
throws. On 24 August the button will produce the refusal, not a proposal.

That refusal is deliberate: a review whose adherence, volume and pace are all
withheld is not a review, and judging a block from the effort table alone would
produce a confident answer built on a quarter of the evidence.

**So the usable evidence pool today is three things** — the bundled plan, the
session notes, and the RPE/feel recorded against them. Everything measured comes
from Strava.

**Phase 4A is what unblocks it**, by rebuilding volume, adherence, pace and
coverage on Apple Health figures.

**Bruno's standing item:** build the data pool used to analyse progress and make
changes to the plan. Sleep, fuel and liquid intake are authored or Health-
derived, so none of them is blocked. A note on 1 August already reads *"Drank
750ml of water during the run"* — the data exists, in free text, where nothing
can count it.

The question worth settling before 4A rather than during it: **is the review's
job to judge the plan against what was DONE, or against how it FELT and how
recovery went?** Today it can only do the second.

## 8. How this project works

- Patches are **zips**, unzipped by the athlete into
  `~/Documents/Developer/sub4/Sub4/Sub4/`; tests into `Sub4CoreTests/`; anything
  at repository level into `~/Documents/Developer/sub4/Sub4/`. Markdown does not
  reach Downloads reliably — **send documents as zips too**.
- **Nothing that is not Swift source goes under `Sub4/Sub4/`.** Synchronized
  groups copy a stray `.py` or `.json` into the app bundle. `tools/` and `docs/`
  live at the repository root for exactly this reason.
- **Large files are edited in place by an `apply-NNN.py` script**, not shipped
  whole. The device bridge truncated two files silently on 5 August — 524 lines
  returned for a 582-line file, 680 for 898 — and a whole-file replacement built
  from a truncated read deletes working code with no error anywhere. Every
  script checks its anchors first and stops without writing if any is missing;
  `--check` reports without touching anything.
- `AppVersion.swift` ships in **every** patch zip with the number bumped. A
  stale number is how you learn the patch did not land.
- Never use Xcode's "Add Files". A **new** file needs ⌘Q and reopen; an
  overwritten one does not. ⌘Q is not needed for terminal `xcodebuild` runs —
  synchronized groups compute target membership from disk at build time.
- No git, and no writing into the repo through the device bridge. Reading is
  fine — **but `git status` through the bridge creates `.git/index.lock` and the
  bridge cannot delete it.** Use `git --no-optional-locks status`.
- Always give exact steps and say where on screen a thing is — **read the view
  first rather than guessing**. Naming a button without checking which store it
  calls cost two round trips on 5 August.

Test command:

```bash
cd ~/Documents/Developer/sub4/Sub4
xcodebuild test -project Sub4.xcodeproj -scheme Sub4 \
```

## 9. What this project keeps re-learning

- **Real data beats tests.** Every serious finding this week came from a number
  on the phone: the sync cursor losing late uploads, the 407 unresolved gear
  ids, the day Today's panel summed kilometres across sports.
- **A test can keep passing long after it has stopped describing the system.**
  `todayEverythingBrokenLooksTheSame` was written to fail when the classifier
  landed. Its assertion stayed true; only its *name* became false, and a green
  run said nothing about the gap.
- **A warning-shaped defect needs a test**, because nothing else in the pipeline
  stops for one. 559 tests passed over three isolation warnings.
- **Enumerate consequences from the mechanism, not the symptoms.** Patch 256
  fixed three consequences of one decision and missed a fourth that shared the
  identical mechanism — the two that had just been on screen got fixed, and the
  third was never looked for.
- **A method written in anticipation is not a feature.** `remove(_:)` compiled
  and was correct and did nothing for 45 patches, because nothing called it.
- **A justification written ahead of the thing it justifies is a prediction.**
  §12.9b argued for `AthleteFile` on isolation grounds about a reader that had
  not been written; when it was written, the reasoning turned out not to apply.
  Marked as corrected rather than edited away.
